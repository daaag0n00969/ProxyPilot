ProxyPilot installs from one file on Windows 10 and 11 (64-bit). No separate .NET install.

Setup places the app in C:\Program Files\ProxyPilot, creates a shortcut, and opens it. An older copy is upgraded in the same folder. Settings in %AppData%\ProxyPilot are kept. A running copy is closed first.

Start Happ first (SOCKS5 on 127.0.0.1:10808). After setup, interception turns on by itself.

Windows SmartScreen may say the publisher is unknown: this build is unsigned. Choose More info, then Run anyway.

If Kaspersky blocks a file, exclude C:\Program Files\ProxyPilot and restore the file from quarantine. That warning is a heuristic on the packet driver, not a virus planted in the build.
